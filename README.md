# EPINOR Account Activator

A small PS5 ELF payload derived from the account-activation logic present in etaHEN's `AccountActivator` implementation.

## What it does

When executed on a PS5 payload environment, it:

1. Initializes UserService.
2. Reads the current foreground user.
3. Finds that user's registry slot.
4. Reads the existing Account ID.
5. If the Account ID is non-zero, it does not modify the account.
6. Otherwise it writes the Account ID generated by the etaHEN algorithm, sets account type to `np`, and sets the account flags to `4098`.
7. Sends a device notification containing the result and `Coded by EPINOR`.

## Build locally

This repository expects the `ps5-payload-dev/sdk` binary distribution and its `PS5_PAYLOAD_SDK` environment variable.

```bash
export PS5_PAYLOAD_SDK=/opt/ps5-payload-sdk
make clean
make
```

Output:

```text
EPINOR-Account-Activator.elf
```

The repository's GitHub Actions workflow installs PS5 Payload SDK v0.42 and builds the same Makefile target automatically. The upstream SDK documentation provides the binary distribution URL and `PS5_PAYLOAD_SDK` workflow; current SDK v0.42 was published on 2026-08-02. citeturn394303search0turn290987search0

## GitHub release flow

- Push the repository to GitHub.
- The **Build PS5 ELF** workflow runs automatically on `main`, pull requests, or manually from **Actions → Build PS5 ELF → Run workflow**.
- To publish a release, create and push a tag such as `v1.0.0`.
- The **Release PS5 ELF** workflow builds the payload and attaches `EPINOR-Account-Activator.elf` and `SHA256SUMS.txt` to the GitHub Release.
